深海番茄 · 使用说明
==================

一、启动
--------
1. 双击本文件夹里的「启动深海番茄.bat」。
2. 浏览器会自动打开番茄钟页面（pomodoro.html）。
   也可以直接双击 pomodoro.html 打开。
3. 不需要登录、不需要联网（只有开启 AI 对话时才需要网络）。
   推荐使用 Edge 或 Chrome。

二、计时
--------
· 顶部可切换「专注 / 小憩」，默认专注 25 分钟、小憩 5 分钟。
· 点「开始专注」开始，再点一次暂停。
· 快捷键：空格 = 开始 / 暂停，R = 重置，S = 跳过当前阶段。
· 计时结束后会响铃，并按设置自动进入下一阶段。
· 刷新或误关页面后，会恢复上次未结束的计时；首次点击页面会启用铃声和音乐。
· 下方四个圆点表示今日的四个番茄目标。
· 点右上角「收起」可变成小窗迷你计时器，点「展开」恢复。
· 右上角还有：任务清单、深色 / 浅色切换、全屏、设置。

三、任务清单
------------
· 在右侧「任务清单」输入内容后点「添加」；点 ★ 可标记为重要。
· 点击任务前的圆圈可标记完成，× 删除任务。
· 排序可切换「默认排序 / 手动排序」，手动排序时用 ↑ ↓ 调整顺序。
· 收起成迷你计时器后，任务也会显示在小窗里。

四、休息音乐
------------
· 进入小憩时会自动播放休息音乐（当前默认：music1.mp3）。
· 点计时器上的「♪」打开迷你歌单，可切换 music1.mp3 / music2.mp3，
  也可以点「+ 导入音乐」导入本地歌曲（可多选，保存在浏览器里）。
· 设置里可调整音量、播放模式（单曲循环 / 轮流播放）和进度条显示。
· 若浏览器拦截自动播放，会出现「打开声音」提示，点一下即可。

五、设置（右上角齿轮）
----------------------
· 专注 / 小憩时长：可精确到秒，点「恢复 25:00 + 05:00」还原默认。
· 深色模式、专注结束自动小憩、小憩结束自动专注。
· 显示网站资源、收起卡片时显示资源栏。
· 困难模式：
    方案一：专注和小憩都不能暂停；
    方案二：专注时一旦暂停，计时会从零重来。
· 连续暂停：每完成设定轮数后自动停下（默认每 4 轮）。
· 专注代码雨：可分别开关「环内 / 环外」的代码雨动画。
· DeepSeek 对话：默认关闭；开启后还需要在对话窗口的「连接设置」里
  填入自己的 API Key 才能使用。
· 清空进度：可清空今日番茄数 / 专注分钟；弹窗中还有删除今日分数、
  清空历史记录等选项。

六、统计与奖励
--------------
· 右下角显示：专注分钟、今日番茄、成就分。
· 完成一次专注获得的成就分 = 专注分钟数（最少 5 分）+ 10 分完成奖励。
· 点「成就分」可打开「成就与奖励」：
    - 自定义目标分和奖励文字（例如 25 分 → 喝杯奶茶）；
    - 达到目标后可点「领取」；
    - 在「历史记录」日历里查看每天的得分。

七、数据保存
------------
· 设置、任务、成绩、歌单都保存在当前浏览器本地，不会上传。
· 换浏览器、清理浏览器数据或使用无痕模式，记录会丢失。
· 自选音乐保存在浏览器的 IndexedDB 中。

八、常见问题
------------
· 没有声音：先点页面上的「打开声音」，再检查系统音量和标签页是否静音。
· 页面打不开：确认 pomodoro.html 还在本文件夹，且没有被杀毒软件隔离。
· 想恢复登录功能：把 spare 里的 login.html、server.js、package.json 和 data
  移回本文件夹，再按启动器和 server.js 里注释掉的登录代码恢复。
· spare 文件夹里是当前番茄钟用不到的旧文件，确认不需要后可自行删除。

九、文件说明
------------
· pomodoro.html：番茄钟主页面，必须保留。
· 启动深海番茄.bat：Windows 启动脚本。
· background1/2/3.png：专注、暂停、小憩背景。
· default.png、whaleStart.png、whaleStop.png、whale-logo.svg：小鲸鱼娘和图标。
· music1.mp3、music2.mp3：内置休息音乐。
· clap.mp3、lose.mp3、rejection.mp3、score.mp3：音效。
· spare：当前番茄钟不使用的旧文件（登录页、旧服务端、旧图片、旧数据库）。
  不使用登录功能时可以整个删除；上传云端时不需要上传 spare。
