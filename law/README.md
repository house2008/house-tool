# 国家法律索引 · 法律正文库

本目录包含“中国特色社会主义法治体系 · 国家法律索引”静态站点，以及 352 部国家级法律、法律解释、决定、修正案的正文页面。

## DOCX 文献库

用户下载的原始 DOCX 保存在 `laws\zip`，共 **737 份**；另有 **4 份原始 `.doc`** 已转换为 DOCX。整理时未改动原始文件。

4 份 `.doc` 的转换结果保存在 `laws\docx-converted`，原始 `.doc` 仍保留在 `laws\zip`。转换后的 DOCX 也已纳入 `laws\library`，因此文献库总数为 741 份。

已在 `laws\library` 中另存并分类：

- 按 **法律类型** 分目录：宪法、宪法相关法、民法商法、行政法、经济法、社会法、生态环境法、刑法、诉讼与非诉讼程序法、有关决定、法律解释、刑法修正案
- 按 **年份** 分目录：如 `1999`、`2020`
- 每份 DOCX 旁边生成同名 `.html` 阅读页和 `.txt` 纯文本
- 全部 741 份文献可在 `library.html` 中按类型、年份筛选，或按标题搜索
- 文献库搜索支持标题/正文、模糊/精确模式；正文索引在首次正文搜索时按需加载
- 原文件下载链接保留在每份文献页面中

统计：

- 文件总数：741 份（737 份 DOCX + 4 份由 DOC 转换）
- 去重后的法律/文献：565 部
- 现行/尚未生效版本：344 份
- 历史版本：171 份
- 有关决定：218 份

全部 352 个索引条目均已匹配 DOCX，已用于更新 `data\texts` 和现行法律正文页；其中 `e0322`、`e0330` 由原始 `.doc` 转换后补入。

## 检索与排序

- **标题检索 / 正文检索**：可切换“标题+正文”“标题”“正文”。
- **模糊 / 精确检索**：
  - 模糊：空格分隔多个关键词，全部出现即命中，不要求连续。
  - 精确：按完整短语连续匹配。
- 正文检索使用 `data\search-index.js`，首次正文搜索时按需加载，不拖慢首页。
- 搜索结果会显示正文命中片段并高亮关键词。
- 默认按**公布日期从早到晚**排列，索引编号 0001—0352 即时间顺序。
- 可切换“按分类”查看宪法、现行有效法律、尚未生效、法律解释、决定、修正案等分组。
- 排序选择会记住，下次打开仍按上次选择显示。
- 排序方式独立放在搜索框外，切换“按时间 / 按分类”不受筛选栏收起影响。
- 搜索框下方的“范围 / 模式 / 分类筛选”区域可点击“收起 / 筛选”按钮隐藏或显示，状态也会记住。
- `library.html` 与 `index.html` 使用同一种搜索卡片样式，支持按 `/` 或 `Ctrl/Cmd + K` 聚焦搜索框、清除按钮和筛选栏收起。
- 点击索引条目或文献库条目会在新标签页打开对应正文页；正文页因此不再提供“返回”按钮，关闭标签页即可回到原列表。
- 搜索结果数量显示在排序栏，数据版本与“检查更新”按钮位于页脚，搜索卡片内不再堆放统计文字。
- 点击法律条目会在新标签页打开正文；正文页已移除“返回”链接，关闭标签页即可回到索引。
- `library.html` 的搜索框与首页保持一致，支持 `/` 聚焦、清除按钮和筛选面板收起。

## 正文页内检索

每篇法律正文页右上角有“检索”按钮，也可以按 `Ctrl+F`（Mac `Cmd+F`）打开页内检索：

- 输入一个或多个关键词，空格分隔，例如：`工资 加班 赔偿`
- 所有匹配项以亮黄色高亮，当前定位项用橙色显示
- 显示“第 X / Y 个”
- 点击 `↑` / `↓`，或按 `Enter` / `Shift+Enter` 上一个/下一个
- 下方显示每个关键词的命中数量，点击关键词标签可单独定位该关键词
- 关闭面板或按 `Esc` 清除高亮
- 打印时会自动清除页内高亮，避免把荧光色印出来

## 每日自动更新

- 每次打开页面都会以时间戳加载 `data\laws.js`，避免浏览器缓存旧数据。
- 每天首次打开会检查 `data\version.json`；如果发现本地数据版本变化，会自动刷新页面。
- 页面底部显示当前数据版本；搜索框下方提供“检查更新”按钮，可手动强制检查。
- 直接双击 `index.html`（`file://` 协议）时，浏览器可能禁止读取 `version.json`，此时会显示“本地模式”，但索引、正文和搜索仍可正常使用。

> 说明：这里的“自动更新”是自动加载/刷新本地最新数据版本。若要持续从国家法律法规数据库抓取新增或修订法律，需要另行运行联网更新流程后重新生成数据文件。

## 如何修改正文

1. 直接编辑 `data\texts\eXXXX.txt`。
2. 运行：

```powershell
node E:\law\tools\build-pages.js
```

脚本会：

- 重新生成 `laws\**\eXXXX.html`
- 按公布日期从早到晚重新分配索引编号 `indexNo`
- 更新 `data\manifest.json` 中的字数、条文数、标题数
- 重新生成全文检索索引 `data\search-index.js`
- 同步更新 `data\laws.js` 和 `data\version.json`
- 重新统计“已入库/未入库”数量

如修改了文献库文本，还需运行：

```powershell
node E:\law\tools\build-library-search.js
```

以重建文献库全文检索索引。

## 文本格式

`data\texts\eXXXX.txt` 由“文件头 + 分隔线 + 正文”组成：

```
中华人民共和国宪法（2018年修正文本）
分类：宪法
效力：现行有效
公布：2018年3月11日
施行：2018年3月11日
制定机关：全国人民代表大会
来源：国家法律法规数据库（https://flk.npc.gov.cn）
============================================================

# 序言

中国是世界上历史最悠久的国家之一。……

## 第一章总纲

第一条中华人民共和国是工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家。……
```

约定：

- `#`：编、序言、附则
- `##`：章
- `###`：节
- `第一条……`：每一条单独一段
- `一、`、`（一）`：决定、修正案中的条款
- 段落之间空一行

## 注意事项

- `index.html` 只负责索引与检索，不存放法律正文。
- `laws\` 下的 HTML 为生成产物，重新运行 `build-pages.js` 会覆盖，建议改 `data\texts\` 而不是直接改 HTML。
- 正文由公开文本自动提取、整理，可能存在排版或识别误差；如与官方公布文本不一致，以国家法律法规数据库公布的正式文本为准。
- 本目录为纯静态站点，双击 `index.html` 即可离线使用；如需本地 HTTP 服务，可在本目录运行：

```powershell
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/`。
