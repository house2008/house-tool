国家法律索引 · 家庭使用说明
============================================================

这份说明是给家里人用的，主要解决三件事：

1. 快速查到现行法律名称和条文；
2. 遇到纠纷时，知道先查什么、保存什么、找谁处理；
3. 不把“查到法条”当成“已经请了律师”，重要事情仍要咨询专业律师。

建议先看最后的“快速开始”，再按需要翻前面的内容。


一、怎么打开
------------------------------------------------------------
1. 双击 E:\law\index.html，打开“国家法律索引”。
2. 想看所有历史版本、法律解释、决定和修正案，双击 E:\law\library.html，打开“法律文献库”。
3. 建议使用 Edge 或 Chrome 浏览器。
4. 整个 E:\law 文件夹要一起拷贝，不要只拷 index.html；拷到 U 盘或移动硬盘时也一样。
5. 如果页面空白或打不开，先确认 data、assets、laws 这三个文件夹还在原来的位置。
6. 本网站可以离线使用；如果页脚显示“本地模式”，不影响查询和阅读。


二、首页怎么查
------------------------------------------------------------
1. 在搜索框输入关键词，例如：
   民法典、劳动合同、离婚、继承、借款、交通事故、未成年人、消费者。

2. 选择搜索范围：
   - 标题+正文：最常用；
   - 标题：只知道法律名称时；
   - 正文：记得某句话或某个法律概念时。

3. 选择搜索模式：
   - 模糊：多个关键词用空格分开，全部出现即可，例如“劳动 加班 工资”；
   - 精确：按完整短语连续匹配，例如“善意取得”。

4. 搜索后：
   - 标题中命中的关键词显示亮黄色；
   - 正文摘要中命中的关键词显示深米黄色。

5. 点击法律条目，会先打开“详情”弹窗：
   - 可以看到索引编号、所属分类、效力状态、正文入库字数；
   - 点“阅读全文 →”，会在新标签页打开正文；
   - 关闭新标签页即可回到索引页。

6. 首页排序：
   - “按时间”：按公布日期从早到晚；
   - “按分类”：按宪法、民法商法、行政法、经济法、社会法、生态环境法、刑法、诉讼与非诉讼程序法等类型分组；
   - 选择会被记住，下次打开仍按上次选择显示。

7. 搜索框下方的“筛选 / 收起”按钮：
   - 可以隐藏或显示“范围、模式、分类标签”区域；
   - 状态也会被记住。

8. 首页编号 0001—0352 是按公布时间排列的“索引编号”，不是法律条文号。


二点五、看正文时怎么在页内找词
------------------------------------------------------------
1. 打开某部法律正文后，点右上角“检索”，或者按 Ctrl+F。
2. 输入一个或多个关键词，多个词用空格分开，例如：工资 加班 赔偿。
3. 所有匹配的地方显示亮黄色，当前定位的地方显示橙色。
4. 点 ↑ / ↓ 按钮，或按 Enter / Shift+Enter，跳到上一个 / 下一个。
5. 下面的关键词标签会显示每个词出现了多少次；点某个词，可以单独定位这个词。
6. 按 Esc 关闭检索，黄色高亮会清除。
7. 打印时高亮会自动清除，不会印出荧光色。


三、文献库怎么用
------------------------------------------------------------
1. library.html 收录 741 份文献，包括：
   - 现行法律；
   - 历史版本；
   - 法律解释；
   - 有关法律问题和重大问题的决定；
   - 刑法修正案。

2. 可以按“法律类型”和“年份”筛选。
3. 搜索支持标题和正文，也支持模糊、精确模式。
4. 点“阅读”在新标签页看正文；点“DOCX”下载原始文件。
5. 想查某部法律“以前怎么规定”的，可以在文献库找历史版本。
6. 处理当前纠纷，优先看“现行有效”的版本；历史版本只作参考。


四、查法律时的三个关键动作
------------------------------------------------------------
1. 先确认“是不是现行有效”
   - 看条目上的状态：现行有效 / 尚未生效 / 历史版本 / 有关决定。
   - 看公布日期和施行日期。
   - 不要拿已经废止的旧版本去和别人理论。

2. 记下“法律名称 + 第几条”
   - 例如：《中华人民共和国民法典》第一千零七十九条。
   - 截图或打印时，把法律名称、条文号、公布日期一起带上。

3. 保存官方原文
   - 正文页右上角有“打印 / 另存 PDF”。
   - 文献库可以下载 DOCX 原始文件。
   - 最终以国家法律法规数据库（flk.npc.gov.cn）公布的文本为准。


五、遇到纠纷，先做这五步
------------------------------------------------------------
1. 冷静：不签字、不转账、不删除记录。
2. 保存证据：合同、收据、转账记录、聊天记录、通话录音、病历、工资条、考勤、现场照片、报警回执。
3. 查法律：用本索引查关键词，确认现行条文。
4. 找对部门：先找能管这件事的机关或组织，不要只靠吵架。
5. 重要事项咨询律师或法律援助，不要自己硬扛。


六、常用电话
------------------------------------------------------------
110    报警 / 人身安全受到威胁
120    急救
119    火灾 / 救援
12345  政务服务便民热线（不知道找谁时可以先打）
12348  公共法律服务热线（法律咨询、法律援助）
12333  人力资源和社会保障（劳动、社保、工伤）
12315  消费者投诉举报
12338  妇女维权
12355  青少年服务
12368  人民法院诉讼服务
12309  检察服务

提示：紧急危险先打 110；涉及生命危险先打 120。


七、常见生活场景查什么
------------------------------------------------------------
【婚姻家庭】
- 结婚、离婚、夫妻财产、子女抚养：民法典 婚姻家庭编
- 家庭暴力：反家庭暴力法；紧急情况先报警 110，必要时向法院申请人身安全保护令
- 未成年人保护：未成年人保护法
- 老人赡养：老年人权益保障法

【劳动打工】
- 劳动合同、辞退、加班工资：劳动法、劳动合同法
- 社保、工伤：社会保险法
- 劳动仲裁：劳动争议调解仲裁法
- 工伤认定和工伤保险的具体办法属于行政法规或地方规定，本库以法律为主，需要再查当地人社部门

【借钱 / 欠钱】
- 借款合同、利息、担保：民法典 合同编
- 起诉、证据、诉讼时效：民事诉讼法、民法典
- 遇到诈骗：刑法中诈骗罪相关条文；立即报警 110

【买卖 / 消费】
- 退货、假货、欺诈：消费者权益保护法
- 产品质量：产品质量法
- 食品安全：食品安全法
- 网购纠纷：电子商务法、消费者权益保护法

【房子 / 物业】
- 买房、租房、物业、相邻关系：民法典 物权编、合同编
- 房地产开发、交易：城市房地产管理法

【交通事故】
- 责任认定、赔偿：道路交通安全法、民法典 侵权责任编
- 受伤治疗：保存病历、票据、事故认定书

【继承】
- 遗嘱、法定继承、遗产分配：民法典 继承编

【治安 / 行政处罚】
- 打架、扰乱秩序、拘留罚款：治安管理处罚法
- 对处罚不服：行政处罚法、行政复议法、行政诉讼法

【打官司】
- 民事诉讼：民事诉讼法
- 刑事诉讼：刑事诉讼法
- 行政诉讼：行政诉讼法
- 仲裁：仲裁法


八、几个重要时间
------------------------------------------------------------
- 民事诉讼时效：一般 3 年（民法典）
- 劳动仲裁申请：一般 1 年（劳动争议调解仲裁法）
- 工伤认定申请：一般 1 年内（工伤保险条例，属于行政法规）
- 行政复议：一般 60 日内
- 行政诉讼：一般 6 个月内
- 民事判决上诉：一般 15 日内；裁定 10 日内

以上只是常见期限，具体案件可能有例外。涉及期限的，务必尽快咨询律师或拨打 12348。


九、怎么申请法律援助
------------------------------------------------------------
1. 拨打 12348，或去当地司法局 / 法律援助中心。
2. 带上身份证、经济困难证明、案件材料。
3. 常见事项：请求支付劳动报酬、工伤、交通事故、赡养费、抚养费、家庭暴力、见义勇为等。
4. 符合条件的，法律援助中心会安排律师，通常不收费或减免费用。
5. 不要相信“包赢”“有关系”“先交一大笔钱”的非正规法律服务机构。


十、使用法律武器时的底线
------------------------------------------------------------
1. 不伪造证据、不威胁证人、不虚假诉讼。
2. 不采取堵门、打砸、非法拘禁、骚扰家人等违法方式。
3. 录音录像一般应在自己参与的对话或公共场所进行；公开传播要谨慎，具体可咨询律师。
4. 网络曝光注意保护他人隐私和个人信息，避免侵权。
5. 涉及刑事风险的事情，先咨询律师再行动。


十一、重要提醒
------------------------------------------------------------
1. 本索引是查询工具，不是律师意见；重大、复杂事项请咨询执业律师。
2. 法律会修改，页面数据有版本日期；以国家法律法规数据库最新公布的文本为准。
3. 正文由 DOCX 和公开文本自动提取，可能有排版或识别误差；关键条文请核对官方原文。
4. 本库以“法律”为主，行政法规、地方性法规、司法解释、部门规章不一定齐全；需要时再到国家法律法规数据库查询。
5. 家里人共用时，不要随意删除 data、assets、laws 文件夹；更新数据前先备份。
6. 如果要把网站拷给别人，请拷贝整个 E:\law 文件夹，否则搜索和正文可能打不开。


十二、快速开始（给不熟悉电脑的家人）
------------------------------------------------------------
1. 打开 E:\law\index.html
2. 在搜索框输入“离婚”
3. 点“中华人民共和国民法典”
4. 在弹窗里点“阅读全文”
5. 在打开的页面里按 Ctrl+F，输入“离婚”
6. 找到相关条文后，点右上角“打印 / 另存 PDF”
7. 有不懂的，拨打 12348 咨询律师

再提醒一次：
查到法条只是第一步，保存证据、找对部门、注意期限、及时咨询专业人士，才是真正“用好法律武器”。
